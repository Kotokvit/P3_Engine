# Инструкция по запуску O3DE Лаунчера и Редактора для P³ Engine

В рамках архитектуры движка P³ мы используем скомпилированную графическую оболочку и лаунчер **Open 3D Engine (O3DE)** в качестве фронтенда редактора и меню, в то время как вычисления, физика и квантовое ядро работают на **Zig**.

---

## 🚀 Быстрый запуск в одну команду

В корне репозитория или через терминал запустите:

```bash
./tools/launch_o3de.sh
```

Или из любой папки домашней директории:
```bash
~/launch_o3de.sh
```

### Что делает скрипт автоматически:
1. Проверяет наличие запущенного `AssetProcessor` (фоновый сервис шейдеров и ассетов).
2. Запускает его в фоновом режиме, если он еще не активен.
3. Открывает полноценное окно **O3DE Editor / Launcher** для проекта `~/o3de_game_project`.

---

## 🎮 Режимы запуска

### 1. 3D-Редактор сцены (Editor)
```bash
/opt/O3DE/26.05/bin/Linux/profile/Default/Editor --project-path /home/vitalij/o3de_game_project
```
* **Вход в игровой режим (Play In Editor):** Нажмите **`Ctrl + G`**. Включается управление персонажем, физика и камера.
* **Выход из игрового режима:** Нажмите **`Esc`**.
* **3D Навигация:** Зажатие правой кнопки мыши (ПКМ) + `WASD` для свободного полета камеры по сцене.

---

### 2. Прямой запуск Игрового Клиента (Game Launcher)
Для запуска игры напрямую без редактора и инструментов:
```bash
/opt/O3DE/26.05/bin/Linux/profile/Default/O3DE.GameLauncher --project-path /home/vitalij/o3de_game_project
```

---

### 3. Менеджер проектов O3DE (Project Manager)
Для управления списком проектов, настройками и Gems:
```bash
/opt/O3DE/26.05/bin/Linux/profile/Default/o3de
```

---

## ⚙️ Структура интеграции
* `tools/launch_o3de.sh` — Скрипт автоматического запуска лаунчера.
* `~/o3de_game_project/` — Проект игрового пространства и сцен.
* `/opt/O3DE/26.05/bin/` — Системные бинарные файлы оболочки и интерфейса.
* `src/` — Ядро P³ Engine на чистом Zig.
